# 配膳ロボのソースコード

## ファイル構成
pcディレクトリにはPC側の通信用コードを
spikeディレクトリにはSPIKE(レゴ)側のコードを
置いています。

## 実行方法
[Pybricks Code](https://code.pybricks.com/)を開いて、
spikeディレクトリ内のファイルをアップロードし、以下を行うことで実行できる。

1. SPIKEの中央ボタンを長押しして起動する
2. Pybricks CodeでBluetoothマークのボタンからSPIKEとペア接続する
3. main.pyを開いた状態で上部の再生ボタン(右向き三角形)を押す

このようにすると、SPIKE側にソースコードが送信されるため、
次からはPCとの接続がなくても、SPIKE単体で実行できる。
